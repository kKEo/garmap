# Building this book

The book is an [mdBook](https://rust-lang.github.io/mdBook/). Its sources are in
`docs/`.

```console
$ cargo install mdbook            # once
$ mdbook serve docs --open        # live preview at http://localhost:3000
$ mdbook build docs               # static site in docs/book/
```

`docs/book/` is ignored by git.

## Diagrams

The SVG files in `docs/src/img/` are generated by `docs/diagrams.py`:

```console
$ uv run python docs/diagrams.py
```

- Each diagram is a self-contained card with its own background, so it reads the same
  in every mdBook theme.
- `corridor.svg` is drawn from `resources/Lajkonik_250km_.final.gpx` with
  `garmap.corridor.build_corridor`, so it changes if the corridor code changes.
- The other diagrams are schematic. Update the generator when the behaviour they
  describe changes, then re-run it and commit the SVGs.

| Diagram | Describes |
|---|---|
| `pipeline.svg` | the six build stages |
| `modules.svg` | module imports |
| `corridor.svg` | route, corridors and the buffering steps |
| `set-cover.svg` | extract selection |
| `cache-flow.svg` | `http.download` |
| `mapids.svg` | map-id blocks and renumbering |
| `style-typ.svg` | style patching and the TYP |
| `install-flow.svg` | `garmap install` |
